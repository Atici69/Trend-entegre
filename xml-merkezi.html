XML Ürün Merkezi

XML dosyanızı yükleyin, ürün fiyatlarına yüzde artış uygulayın ve seçtiğiniz ürünleri Excel uyumlu dosya olarak dışa aktarın.

1. XML kaynağını seçin

Bağlantı okuma, tedarikçi sunucusunun tarayıcı erişimine (CORS) izin vermesine bağlıdır.
Henüz XML yüklenmedi.

Excel'i XML'e dönüştür

.xlsx, .xls veya .csv dosyanızı yükleyin. İlk satır sütun başlıkları olarak kullanılır; her satır bir XML ürün kaydına dönüştürülür.

Henüz Excel dosyası seçilmedi.
Excel dosyanızı seçtiğinizde ilk ürünler burada görüntülenir.

Bu işlem genel ürün XML'i oluşturur. Pazaryerine özel XML şemaları için hedef pazaryerinin zorunlu alanları ayrıca eşleştirilmelidir. Dosya tarayıcınızda işlenir.

2. Ürünleri inceleyin ve dışa aktarın

Bulunan ürün: 0
Gösterilen: 0
Algılanan alan: 0

Yüzde artış tanınan fiyat alanlarına uygulanır. Orijinal fiyatlar korunur; dışa aktarılan dosyada ayrıca yeni fiyat sütunları bulunur.

Önce bir XML dosyası yükleyin veya bağlantıyı deneyin.

Excel (.xlsx) dosyası cihazınızda oluşturulur; orijinal fiyatlar korunur ve artış uygulanmış fiyatlar ayrı sütunlara eklenir. XML tarayıcıda işlenir, sunucuya gönderilmez. Bağlantı CORS nedeniyle engellenirse XML dosyasını indirip yükleyin.
